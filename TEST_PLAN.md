# План тестирования проекта «Котоскролл»

## 1. Цель

Проверить, что локальный сайт открывается, показывает все материалы и правильно выполняет основные функции: прокрутку ленты, работу вкладок, избранное, просмотр фотографий и королевскую битву.

## 2. Виды тестирования

- Проверка структуры проекта и медиафайлов.
- Функциональное тестирование JavaScript и элементов страницы.
- Негативное тестирование ошибок загрузки и повреждённого `localStorage`.
- Сквозное тестирование в настоящем браузере Chromium.
- Проверка мобильной вёрстки.
- Ручное тестирование внешнего вида, звука и удобства использования.
