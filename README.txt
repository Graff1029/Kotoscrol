Проект «Котоскролл» 🐾
=====================

Этот проект — локальный сайт про видео и фотографии с котиками. 
Он работает полностью без интернета и серверов.

Как запустить сайт:
-------------------
1. Распакуйте архив в любую удобную папку на вашем компьютере.
2. Просто дважды кликните по файлу `index.html`. Он откроется в вашем браузере по умолчанию.

Где лежат медиафайлы:
---------------------
В папке проекта есть папка `assets`. Внутри неё две папки:
- `assets/videos/` — сюда нужно класть скачанные вертикальные видео с котиками.
- `assets/photos/` — сюда нужно класть фотографии.

Как добавить свои материалы на сайт:
------------------------------------
1. Скачанные ролики нужно положить в `assets/videos/` и назвать `cat1.mp4`, `cat2.mp4` и так далее (или изменить названия прямо в коде `script.js`).
2. ВНИМАНИЕ: простое переименование файла другого формата (например, из .mov, .webm или файлов без расширения) в .mp4 не является конвертацией! Убедитесь, что ваши видео действительно скачаны или сохранены с кодеком H.264 и звуком AAC. Иначе браузер может отказаться их воспроизводить локально.
3. Откройте файл `script.js` в любом текстовом редакторе (например, Блокнот).
4. В самом начале файла вы увидите массив `mediaItems`. 
5. Чтобы добавить новое видео, добавьте новую строчку по аналогии:
   { id: 15, type: "video", src: "assets/videos/название_вашего_видео.mp4", title: "Свой заголовок" },

Особенности звука в проекте (обновлено):
----------------------------------------
- В ленте видео запускаются без звука автоматически (из-за ограничений браузеров).
- Вы можете включить звук на центральной карточке. Настройка запоминается: если звук включён, при свайпе следующее видео запустится сразу со звуком.
- В "Королевской битве" и "Избранном" добавлены кнопки звука на сами карточки.
- Одновременно звук в турнире или ленте будет работать только у одного видео.
