Тесты находятся отдельно от сайта в папке `tests`. Основные файлы сайта и расположение медиа остались прежними.

## Как запустить

Нужен установленный Node.js версии 20 или новее.

Откройте терминал в папке проекта и выполните:

```bash
npm install
npm run test:e2e:install
npm test
```

Команда `npm run test:e2e:install` нужна только перед первым запуском. Она устанавливает Chromium для браузерных тестов.

Можно запускать тесты отдельно:

```bash
npm run test:unit
npm run test:e2e
```

- `npm run test:unit` — проверки файлов и функций сайта.
- `npm run test:e2e` — проверка сайта в настоящем браузере.

Подробный список сценариев находится в `TEST_PLAN.md`, краткий отчёт — в `TEST_REPORT.md`.
